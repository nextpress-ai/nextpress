# Media

The **Media Library** holds the pictures, videos, audio files and documents of one site. A file uploaded to one site is not listed on another.

## What you can upload

- Pictures: JPEG, PNG, GIF, WebP and SVG.
- Video: MP4 and WebM.
- Audio: MP3 and WAV.
- Documents: PDF and plain text.
- Up to 10 MB per file. An SVG may be up to 512 KB.

NextPress removes scripts and outside links from an uploaded SVG. If an SVG cannot be cleaned, the upload is refused with "This SVG can't be used. Export it again as a plain SVG and try once more." Pictures are stored as uploaded. They are not resized, so upload them at the size you need.

## Upload a file

1. Open **Media** in the sidebar, under **Content**.
2. Press **Add New Media**.
3. In **Upload Media**, press **Choose File**, or drag a file onto the box.
4. Wait for the upload to finish. The file appears in the list.

## Find a file

- Type in **Search media...** to find a file by name or alt text.
- Use the type filter to show **All Media**, **Images**, **Videos**, **Audio** or **Documents**.
- Switch between the card view and the table view.
- In the table view, click **Name**, **Type**, **Size** or **Uploaded** to sort.

## Add alt text and a caption

1. On the file, press **Edit details**.
2. In **Edit Media Details**, fill in the fields:
   - **Alt Text**: one sentence describing the picture for people who cannot see it, such as "Two people reviewing a floor plan at a desk". Leave it empty only for decorative pictures.
   - **Caption**: a line shown with the media on the page.
   - **Description**: extra notes.
3. Press **Save Changes**.

## Use a file in a block

1. Add an **Image**, **Gallery**, **Video**, **Audio**, **Cover**, **Media & Text** or **File** block to a page.
2. Select the block. In its **Content** tab, choose a file from the media library, or upload a new one there.
3. Press **Save**.

## Delete a file

1. On the file, press **Delete media**, or select several files in the table view.
2. Confirm.

Deleting cannot be undone. A page that still uses the file shows a broken picture or link, so check the pages that use it first.
