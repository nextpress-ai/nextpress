# Site settings

**Settings** is in the sidebar, under **System**. It belongs to the site chosen in the site picker, and only that site's admins and owner can open it. Others see "Only this site's admins change its settings."

Press **Save Changes** at the top to save the **General**, **Reading** and **Discussion** tabs. The **AI** tab saves on its own.

## Your account

Your name, email and password. See [Passwords and reset](/docs/people/passwords-and-reset). The same panel is in the sidebar as **Your account**.

## General

| Field | What it does |
|---|---|
| Site Title | The site's name |
| Admin Email | The email address recorded as the site's admin contact |
| Site Description | A short description, used in link previews and search results when a page has none |
| Site URL | The site's address, with a check that it points at the server |
| Site homepage | The published page visitors see at the site's main address |
| Timezone | The time zone for post dates on the site. It shows the current time there |
| Site Logo | PNG, JPG or SVG, up to 5 MB |
| Favicon | The small icon in the browser tab. PNG or ICO, up to 5 MB |
| Active Theme | The site's theme |

## Reading

| Field | What it does |
|---|---|
| Site homepage | The same choice as on **General** |
| Posts in the RSS feed | How many posts the feed lists, from 1 to 100 |
| RSS feed | Turns the feed at `/feed` on or off. When off, `/feed` answers "This site has no feed" |
| Link and search description | Where a page's description comes from: **Page, then excerpt, then the site**, **The page description**, **The excerpt** or **The site description**. A page can choose its own in **Page settings** |
| Search Engine Visibility | Asks search engines not to index the site |

## Discussion

| Field | What it does |
|---|---|
| Allow comments | Visitors can comment on this site's posts |
| Review comments first | New comments show only after someone approves them in **Comments** |
| Let visitors create an account | Visitors can sign up. They can comment and keep a profile, nothing more |

Comments and review are on by default. Visitor accounts are off by default. See [Comments](/docs/content/comments).

## AI

The AI service, model and key for the page assistant. See [Set up AI](/docs/ai/set-up-ai).

## System

- **System Information**: facts about the install and its version.
- **API Keys**: create, change and revoke keys. See [API keys](/docs/developers/api-keys).

## Settings on each page

Some choices are made per page in **Page settings** in the page builder: title, address, status, homepage, featured image, comments, password, parent page, menu order, meta title and description, canonical URL, hiding from search engines, and custom meta tags. See [Page builder basics](/docs/building-pages/page-builder-basics).
