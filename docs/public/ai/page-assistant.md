# Use the page assistant

The page assistant changes the page you have open in the page builder. You describe what you want in plain words, and its changes appear on the canvas. They are kept on the page only when you press **Save**.

The assistant must be set up first. See [Set up AI](/docs/ai/set-up-ai). Editors, admins and owners can use it. Every request uses the site's AI key.

## Build a new page from a description

1. Press **New**, pick **Page**.
2. In **New page**, type a **Title**.
3. In **Describe your page (optional)**, describe it, such as "A landing page for a yoga studio: a hero with a booking button, class times, prices and a contact form".
4. Press **Create page**.

The editor opens and the assistant builds a first draft. Nothing is published.

## Change a page

1. In the page builder, open the **Assistant** tab in the left panel.
2. Type your request, such as "Add a pricing section with three plans". Press Enter to send. Shift+Enter starts a new line.
3. Watch the steps, such as "Reading the page" or "Adding Heading". Changed blocks show on the canvas.
4. To stop, press the stop button in the message box.
5. Check the page, then press **Save**.

While the assistant works, the rest of the editor is locked. Under each reply, a line says what changed.

## Change one block

1. Select a block on the canvas.
2. Press **AI** on its toolbar, or Ctrl+J (Command+J on a Mac).
3. Type the change, such as "Make this shorter and friendlier", or pick **Make it shorter**, **Make it friendlier** or **Fix it for phones**.

The full conversation stays in the **Assistant** tab.

## Take changes back

- Each request is one undo step. Press **Undo** to take back everything one request changed.
- Under a reply, press **Go back to before this** to return the page to how it was before that reply. This can be undone too.

## Chats

Each page keeps its own chats. They are saved for you only. Use the chat list to open an earlier chat, or start a **New chat**. Deleting a chat does not change the page.

## Removing many blocks

If one change would remove more than 10 blocks, counting blocks inside other blocks, the assistant asks "This change removes more than ten blocks. Go ahead?" and waits for your answer.

## Limits

- One request at a time for each person. A second one says "The assistant is already working on a page for you."
- Up to 30 requests an hour for each person. After that: "You've asked the assistant too many times this hour. Try again later."
- Each request runs for up to 3 minutes and up to 25 steps.

## Writing good requests

- Name the section and the change: "In the hero, make the button say Book a class."
- Give the purpose: "This page is for first-time visitors, so keep it short."
- Ask for one section at a time.
